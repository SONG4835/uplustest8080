## 요금제 목록

### 목적
사용자가 요금제의 제공 사항과 월 요금을 비교하고 상세 화면으로 진입한다.

### 라우트
`/plans`

### 구성 요소
- Header
  - Type=root
  - 제목: "요금제"
  - 내부 구성: Logo
- 안내 문구
  - "나에게 맞는 요금제를 골라보세요"
  - "중요하게 보는 조건을 고르면 추천해 드려요"
- FilterChip
  - "데이터 많이": State=selected
  - "가성비", "구독 포함", "통화 많이": State=default
- 목록 안내: "추천순 · 4개"
- Card/Plan
  - State=default
  - 넉넉 무제한
    - 데이터 무제한 · 통화 무제한 · 넷플릭스 포함
    - 월 85,000원 / 기존 월 100,000원 / 할인율 15%
    - Tag: "추천"
    - Chip: Type=sale, "24개월 할인 프로모션"
  - 스탠다드 110
    - 데이터 110GB · 통화 무제한
    - 월 69,000원 / 기존 월 78,000원 / 할인율 12%
    - Chip: Type=sale, "24개월 할인 프로모션"
  - 라이트 30
    - 데이터 30GB · 통화 무제한
    - 월 49,000원
    - 추천 배지·할인·프로모션 미표시
  - 슬림 10
    - 데이터 10GB · 통화 무제한
    - 월 39,000원 / 기존 월 43,000원 / 할인율 10%
    - 추천 배지·프로모션 미표시
- Button
  - 각 Card/Plan 내부에 "자세히"
  - Type=Secondary, Size=sm, State=Default

### 상태
- 기본: "데이터 많이"가 선택되어 있고 요금제 4개를 추천순으로 표시한다.
- 로딩: 미정. 템플릿에 로딩 UI가 없다.
- 빈: 미정. 필터 결과가 없는 경우의 문구와 UI가 없다.
- 에러: 미정. 목록 조회 실패 시 안내와 재시도 UI가 없다.

### 이동
- 들어오는 곳:
  - 직접 진입 또는 외부 진입 경로: 미정.
  - 제안: 신청 완료 화면의 "요금제 더 보기"에서 진입한다.
- 나가는 곳:
  - 제안: 요금제의 "자세히"를 누르면 해당 요금제의 `/plans/[id]`로 이동한다.
  - 필터 선택 방식과 URL 반영 여부: 미정.

## 요금제 상세

### 목적
선택한 요금제의 월 요금, 기본 제공 사항, 포함 혜택을 확인하고 구독 신청을 시작한다.

### 라우트
`/plans/[id]`

### 구성 요소
- Header
  - Type=default
  - 제목: "요금제 상세"
  - 내부 구성: icon/arrowLeft
- Tag
  - 문구: "추천"
- 요금제 안내 문구
  - "넉넉 무제한"
  - "영상·게임을 하루 종일 해도 걱정 없어요"
- Card/Price
  - 월 요금: 85,000원
  - 할인율: 15%
  - 기존 요금: 100,000원/월
  - "24개월 할인 프로모션 적용"
- List/Row
  - 기본 제공: Type=default
    - 데이터: 무제한
    - 통화: 집·이동전화 무제한
    - 문자: 기본 제공
  - 포함 혜택: Type=check
    - 넷플릭스 스탠다드: 포함
    - 유튜브 프리미엄: 포함
- BottomCTA
  - Layout=price
  - 월 납부 금액: 월 85,000원
- Button
  - BottomCTA 내부에 "구독 신청하기"
  - Type=Primary, Size=xl, State=Default

### 상태
- 기본: 예시 요금제 "넉넉 무제한"의 요금·제공 사항·혜택을 표시한다.
- 로딩: 미정. 상세 조회 중 UI가 없다.
- 빈: 미정. 해당 id의 요금제가 없는 경우 처리 정의가 없다.
- 에러: 미정. 상세 조회 실패 시 안내와 재시도 UI가 없다.

### 이동
- 들어오는 곳:
  - 제안: `/plans`에서 해당 요금제의 "자세히"를 누르면 진입한다.
  - 직접 진입 시 id 처리: 미정.
- 나가는 곳:
  - 제안: "구독 신청하기"를 누르면 선택한 요금제 정보를 유지하여 `/apply`로 이동한다.
  - 제안: icon/arrowLeft를 누르면 `/plans`로 돌아간다.
  - 선택한 요금제 정보의 전달 방식: 미정.

## 구독 신청

### 목적
선택한 요금제를 확인하고 신청자 정보와 필수 개인정보 동의를 받아 구독을 신청한다.

### 라우트
`/apply`

### 구성 요소
- Header
  - Type=default
  - 제목: "구독 신청"
  - 내부 구성: icon/arrowLeft
- 안내 문구
  - "신청 정보를 입력해주세요"
- List/Row
  - Type=default
  - 선택한 요금제: 넉넉 무제한
  - 월 요금: 85,000원
- Input
  - 이름
    - 예시 값: 김유플
    - State=filled
  - 휴대폰 번호
    - 예시 값: 010-1234-5678
    - State=focus
- Checkbox
  - State=active
  - "[필수] 개인정보 수집·이용에 동의합니다"
- BottomCTA
  - Layout=single
- Button
  - BottomCTA 내부에 "신청하기"
  - Type=Primary, Size=xl, State=Default

### 상태
- 기본: 선택한 요금제와 월 요금을 표시한다. 템플릿에는 이름·휴대폰 번호가 입력되어 있고 필수 동의가 선택되어 있다. 실제 최초 진입 시 입력값과 동의 상태는 미정이다.
- 로딩: 미정. 신청 전송 중 표시와 중복 제출 방지 정책이 없다.
- 빈: 미정. 선택한 요금제 정보가 없거나 입력값이 비어 있는 경우 처리 정의가 없다.
- 에러: 미정. 이름·휴대폰 번호 검증 규칙, 필수 동의 누락 안내, 신청 실패 처리가 없다. 라이브러리에는 Input의 State=caution이 있으나 이 화면에서의 적용은 확인되지 않았다.

### 이동
- 들어오는 곳:
  - 제안: `/plans/[id]`의 "구독 신청하기"에서 선택한 요금제 정보를 전달받아 진입한다.
- 나가는 곳:
  - 제안: "신청하기"를 누른 뒤 신청이 성공하면 `/complete`로 이동한다.
  - 제안: icon/arrowLeft를 누르면 선택한 요금제의 `/plans/[id]`로 돌아간다.
  - 뒤로 이동 시 입력값 유지 여부: 미정.
  - 신청 실패 시 이동 또는 화면 유지 정책: 미정.

## 신청 완료

### 목적
구독 신청 완료를 알리고 신청 내역과 이후 안내 방법을 확인하게 한다.

### 라우트
`/complete`

### 구성 요소
- Header
  - Type=default
  - 제목: "신청 완료"
  - 내부 구성: icon/arrowLeft
- icon/doneMark
  - 내부 구성: icon/check
- 완료 안내 문구
  - "구독 신청이 완료됐어요"
  - "개통 안내는 문자로 보내드려요"
- 신청 내역 제목
  - "신청 내역"
- List/Row
  - Type=default
  - 신청 번호: 2026-1013-0024
  - 요금제: 넉넉 무제한
  - 월 요금: 85,000원
  - 신청 일시: 10월 13일 14:02
  - 신청자: 김*플 · 010-****-5678
- BottomCTA
  - Layout=single
- Button
  - BottomCTA 내부에 "요금제 더 보기"
  - Type=Primary, Size=xl, State=Default

### 상태
- 기본: 신청 완료 안내와 신청 내역을 표시한다. 신청자 이름과 휴대폰 번호는 마스킹되어 있다.
- 로딩: 미정. 신청 내역 조회 중 UI가 없다.
- 빈: 미정. 신청 내역 없이 직접 진입하거나 새로고침했을 때 처리 정의가 없다.
- 에러: 미정. 신청 내역 조회 실패 시 안내와 재시도 UI가 없다.

### 이동
- 들어오는 곳:
  - 제안: `/apply`에서 신청이 성공한 경우 진입한다.
- 나가는 곳:
  - 제안: "요금제 더 보기"를 누르면 `/plans`로 이동한다.
  - icon/arrowLeft의 이동 목적지: 미정. 완료 후 신청 화면으로 복귀할 수 있는지 확인이 필요하다.
